# Introduction to Data Science (AIUB, Spring 2024-25)

Course work in R.

- `LAB/lab1.R` to `LAB/lab6.R`: weekly lab exercises, with `LAB/iris.csv` as sample data.
- `Mid-Term Project/`: group project on a diabetes prediction dataset (gender, age, hypertension, heart disease, smoking history, BMI, HbA1c level, blood glucose level, diabetes). It covers missing and invalid values, category typos, mean, median and mode imputation, IQR outlier removal for age, BMI and blood glucose, category encoding and duplicate removal. `project.R` is the script, `remove_duplicate.csv` a cleaned sample and the PDF the group report.

Paths inside the scripts point at the original machines; change them before running.
